GPU tester program · early access

Got a GPU collecting dust?

Before $BNH has a chain, we're testing what regular cards can really do. Three steps: check this device, run the Linux check, join the tester list.

Heads up: no miner or worker software is released yet. Nothing runs on your machine from this page, and testers get no payouts or coins.
Step 1 · 10 seconds

Quick browser check.

Reads what your browser reports about this device's graphics. It runs locally. Nothing is sent anywhere unless you attach it to the sign-up form yourself.

Browsers often hide or round hardware details for privacy, and phones won't be mining rigs. The Linux check in step 2 is what counts.

Step 2 · Linux rigs

Run the real hardware check.

The same commands we run on the project's own RX 470 rig. Remove usernames or hostnames before you share the output.

OS releaselsb_release -a
Kerneluname -r
GPUs + driverslspci -nnk | grep -A3 -E 'VGA|Display'
Vulkan devicesvulkaninfo --summary
GPU permissionsls -l /dev/dri
Project probe (JSON)git clone https://github.com/turnflockoff/Boatsnhoes.meme && cd Boatsnhoes.meme/prototype && python3 -m app.gpu_probe_cli

Missing vulkaninfo? On Ubuntu: sudo apt install vulkan-tools mesa-vulkan-drivers

Straight answers.

Do testers earn $BNH?

No. $BNH doesn't exist yet, and testing isn't paid. When mining opens, it's planned as a fair launch where anyone can mine.

What will run on my machine?

Nothing yet. The first test build will be open source, so you can read every line before installing. Downloads will be signed with published checksums.

Why test before there's a coin?

Because a "GPU-friendly" coin that old GPUs can't actually run is a scam waiting to happen. We publish what works and what breaks.

What does the browser check collect?

Nothing leaves your browser unless you paste or attach the report into the form.

Someone DMed me offering early $BNH or a miner download.

That's a scam. We never DM first and never ask for a recovery phrase. Only trust links on boatsnhoes.meme and the GitHub repo. How to spot fakes.
