01 / The mission

Compute first.
Hype never.

Boats N Hoes explores a small, auditable path from local GPU inference to coordinated useful-compute jobs. We publish what works, what breaks, and what remains unproven.

01 — HARDWARE

Start with what we have

Reported setup: Ryzen 5 5600X, 32 GB RAM, Ubuntu, and two RX 470 cards with different VRAM capacities.

02 — USEFUL WORK

Run real inference

Test a small Vulkan-capable workload on each GPU independently. Measure memory, speed, temperature, and output quality.

03 — VERIFICATION

Check before counting

Validate task outputs, reject duplicate jobs, and independently audit selected results before recording accepted work.

Design boundary

Ethereum is not the compute engine.

The prototype may explore an ERC-20 settlement layer later, after useful work and verification are demonstrated. Ethereum Mainnet uses proof-of-stake; this project is not Ethereum mining and does not secure Ethereum consensus.

Worker receipts and hashes are accounting evidence, not cryptographic proof that a GPU executed a model.

04 / Build sequence

From bench test
to proof of concept.

Milestones are deliberately ordered to prove the hardware before adding infrastructure or token complexity.

M0

Inventory the machine

Capture Ubuntu, kernel, PCI IDs, drivers, Vulkan devices, and permissions.

M1

Run inference per GPU

Complete a small Vulkan smoke test on each card and record benchmark results.

M2

Build the worker agent

Registration, signed job retrieval, execution, receipts, retries, and logs.

M3

Build coordinator + verifier

Job lifecycle, deterministic checks, duplicate rejection, audit sampling, SQLite ledger.

M4

Prove two-worker operation

Run both GPUs independently; test restarts, malformed jobs, and throughput.

M5

Simulate rewards

Calculate hypothetical credits from accepted work. No real payouts.

M6

Consider testnet settlement

Only after the compute prototype works: capped test token, tests, and independent review.
