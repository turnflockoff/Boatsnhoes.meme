Stay safe · read before you click

Don't get boarded.

New coins attract fakes, often before the real thing even exists. Here's what's real today, what we'll never do, and how to check a link before you trust it.

Right now there is no $BNH coin. No token, presale, airdrop, wallet, exchange listing, casino or miner download exists. Anyone selling, giving away or "unlocking" any of these is not us.
What we will never do

If they do this, it isn't us.

Scammers copy logos, names and screenshots. They can't copy these rules, so use them as your test.

1 · Your keys

Ask for your recovery phrase

No real project, support desk or admin ever needs your 12 or 24 words or a private key. Anyone who asks is stealing.

2 · First contact

Message you first

Not on X, Telegram, Discord or email. A "team member" who DMs you first is a scammer, even with our logo and name.

3 · Sales

Sell early coins

There's no presale, private round, whitelist or airdrop. Nothing is for sale. If a coin ever launches, the current plan is a fair launch anyone can mine; that isn't final.

4 · Wallets

Ask you to connect a wallet

There's nothing to connect to. Pages that ask you to "connect", "sync", "validate" or "claim" are built to empty wallets.

5 · Downloads

Send software by DM

Real downloads will only be linked from this site and GitHub. Our test tools run without admin (sudo) rights, and nothing of ours asks you to turn off antivirus.

6 · Money talk

Promise you money

No price, profit or payout talk. Test-network points are simulated bookkeeping, not tokens and not money.

Where the real thing lives

Only two official places.

Website

boatsnhoes.meme

Spelled exactly like that, ending in .meme, nothing before or after. Look-alikes swap letters (boatsnh0es), add words (boatsnhoes-claim, bnh-airdrop) or change the ending (.io, .xyz, .app).

Code

GitHub

All code and plans are public at github.com/turnflockoff/Boatsnhoes.meme. Every change is on record there.

Social accounts

Not announced yet

No social account has been confirmed as official. When one is, it will be listed on this page and on GitHub at the same time. Until then, treat any "official" account as unconfirmed.

  • Type the address yourself or use a bookmark. Don't trust search ads; scammers buy them.
  • A padlock only means the connection is private, not that the site is honest. Check the spelling.
  • Link in a reply, a DM or a "support" ticket? Assume it's fake until you've matched it to this page.
Before you run anything

Check downloads like a pro.

Nothing is released yet. When the first test build ships, it will be open source, linked only here and on GitHub, and signed by at least two named people, so one stolen key can't push a fake. The list of signers will be posted here and on GitHub before that build.

1 · Same files we published?sha256sum -c SHA256SUMS
2 · Signed by enough of the listed people?python -m app.release verify release.json --signers signers.json --root .

Both only read files. If either one says anything other than OK, don't run the software, and tell us (below).

Spotted something?

Report a fake, safely.

Fake site, token or account

Tell us on GitHub

Open an issue on GitHub with the link or a screenshot so others can be warned. Don't click it again or connect anything to it.

Security hole in our code or site

Don't post the details

Please open an issue that says only "security report, please contact me". Leave the details out until we've set up a private way to talk.

Already lost something?

Act fast, then warn others

Stop using that wallet, move what's left to a new wallet made on a device you trust, and report the account to the platform it's on. Nobody can reverse a blockchain transfer: "recovery services" that charge a fee are a second scam.

Straight answers.

Is there a $BNH token I can buy anywhere?

No. No coin or token exists on any chain or exchange. A $BNH you can buy today is someone else's, using the name.

Someone posted a $BNH contract address.

Not ours. We haven't deployed a contract or a chain anywhere. If that ever changes, it will be posted on this site and on GitHub first.

Can I mine $BNH yet?

No. There's no chain to mine. The GPU tester program only checks what regular cards can do, and testers get no coins or payouts.

Is the casino open?

No. Gambling features aren't built, and won't be before licensing and legal review. Any site taking bets in $BNH is not ours.

Why does a meme project need a safety page?

Because fakes show up first. A name people recognise, with no real coin behind it yet, is exactly what scammers look for.
