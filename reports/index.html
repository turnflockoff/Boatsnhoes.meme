Check it yourself

Five minutes, no trust needed.

You need git and Python 3.11+. Get the coordinator's public key from more than one place (this page, the GitHub folder, a project post) and make sure they all match.

1 · Get the files and toolsgit clone https://github.com/turnflockoff/Boatsnhoes.meme && cd Boatsnhoes.meme/prototype && pip install -r requirements.txt
2 · Check everything at oncepython -m app.publish_report check --public-key <coordinator key>
Or one period by hand: file hashes(cd ../reports/<period> && sha256sum -c SHA256SUMS)
Signature and numberspython -m app.rewards verify ../reports/<period>/report.json --db ../reports/<period>/ledger-copy.sqlite3 --public-key <coordinator key>
History unchanged between two periodspython -m app.ledger_copy compare ../reports/<older>/ledger-copy.sqlite3 ../reports/<newer>/ledger-copy.sqlite3

These only read the files. Nothing connects to the network, and no wallet or account is involved.

Straight answers.

Are these points worth anything?

No. They're simulated bookkeeping from a test network that checks whether old GPUs do honest work. There's no coin, no payout, and no promise one will exist.

Why wait 7 days after a period closes?

A ledger copy shows which past jobs were hidden test questions. Posting it late means a rig can't use that to learn which of its jobs are tests while they're still fresh. Those test questions are also retired for good.

What's removed from the ledger copy?

Worker keys, sign-up codes, every prompt and answer, the expected answers of hidden tests, and real owner names (replaced with owner-1, owner-2 and so on). What stays is what you need to re-check the math: who did which job, when, how it was checked, and the points.

Why post on both the site and GitHub?

They're the same files. The site makes them easy to find; GitHub keeps a public history of every change, so a file edited after it was posted would show up there.

What does checking actually prove?

That the coordinator issued the report, that its numbers come from the posted ledger, and that later copies didn't rewrite earlier history. It can't prove the coordinator recorded everything honestly in the first place. The project's threat model on GitHub lists what's still open.
